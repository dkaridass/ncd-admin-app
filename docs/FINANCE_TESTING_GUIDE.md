## 🎯 Overview

This guide covers testing for the Finance module, which handles:
- **Income transactions**: Dîme, Offrande, Action de grâce, Offrande du prophète, Dons
- **Expense transactions**: Dépense
- **Multi-account support**: Cash, Rawbank, Equity, PayPal, Mpesa, OrangeMoney
- **Multi-currency support**: USD and CDF
- **Real-time synchronization** with Firestore
- **Dashboard integration** for KPIs and trends

## 🗄️ Firestore Data Structure

### **Collection:** `/finances`

### **Document Structure:**
```typescript
{
  id: "firestore-doc-id", // Auto-generated by Firestore
  type: "Offrande" | "Dîme" | "Action de grâce" | "Offrande du prophète" | "Dons" | "Dépense",
  amount: 450000, // Number
  currency: "CDF" | "USD",
  account: "Cash" | "Rawbank" | "Equity" | "PayPal" | "Mpesa" | "OrangeMoney",
  date: "2026-01-24", // ISO date string (YYYY-MM-DD)
  memberName?: "Fr. Jean", // Optional - for income transactions
  notes?: "Maintenance Sonorisation", // Optional - often used for expenses
  serviceName?: "1er Culte (Dim)", // Optional - for income transactions
  recordedBy: "Admin", // Name of user who created the record
  receiptUrl?: "https://...", // Optional - URL to receipt/document
  isApproved?: true // Optional - boolean, defaults to true for income, false for expenses
}
```

**Key Fields:**
- `id`: Auto-generated by Firestore (DO NOT set manually)
- `type`: Transaction type (required)
- `amount`: Transaction amount (required, must be > 0)
- `currency`: Currency code (required)
- `account`: Target account (required, defaults to 'Cash' if missing)
- `date`: Transaction date (required, ISO format)
- `recordedBy`: User who created the record (required)

## 🐛 Troubleshooting

### **Issue: Transactions not appearing after creation**

**Possible Causes:**
1. Real-time listener not working
2. Firestore rules blocking read access
3. Transaction created with wrong collection name

**Solutions:**
1. Check browser console for errors
2. Verify Firestore rules allow read access
3. Check collection name is `/finances` (not `/finance`)
4. Verify transaction was created in Firestore Console

---

### **Issue: "Missing or insufficient permissions" error**

**Possible Causes:**
1. Firestore rules not deployed
2. User role doesn't have finance permissions
3. Rules syntax error

**Solutions:**
1. Deploy rules: `firebase deploy --only firestore:rules --project ncd-admin-app`
2. Verify user role in Firebase Console → Authentication
3. Check rules syntax in `firestore.rules`

---

### **Issue: Account balances incorrect**

**Possible Causes:**
1. Transactions missing `account` field
2. Currency mismatch in calculations
3. Expense transactions not subtracting correctly

**Solutions:**
1. Check transactions have `account` field set
2. Verify currency field is correct ("USD" or "CDF")
3. Verify expense transactions have `type: "Dépense"`
4. Check balance calculation logic in `FinancesPage.tsx`

---

### **Issue: Dashboard KPIs not updating**

**Possible Causes:**
1. Real-time listener not connected
2. Calculations using wrong filter
3. Cache issue

**Solutions:**
1. Check browser console for listener errors
2. Verify `financeRecords` state is updating
3. Hard refresh browser (Cmd+Shift+R / Ctrl+Shift+R)
4. Check calculation filters (should exclude expenses for income totals)

---

### **Issue: Batch mode not creating all transactions**

**Possible Causes:**
1. Error in one transaction stops batch
2. Validation failing silently
3. Network timeout

**Solutions:**
1. Check browser console for specific errors
2. Verify all batch rows have valid amounts
3. Check Firestore for partial batch (some transactions created)
4. Try creating transactions one by one to isolate issue

## 📝 Notes

1. **Real-time Sync**: Finance module uses Firestore `onSnapshot` listeners, so changes appear immediately without page refresh.

2. **Account Defaults**: If `account` field is missing, it defaults to 'Cash' for backward compatibility.

3. **Currency Conversion**: Dashboard may convert CDF to USD for comparisons (using exchange rate ~2800 CDF = 1 USD).

4. **Transaction Types**: 
   - Income: Dîme, Offrande, Action de grâce, Offrande du prophète, Dons
   - Expense: Dépense

5. **ID Generation**: Firestore automatically generates document IDs. DO NOT set `id` manually when creating records.
