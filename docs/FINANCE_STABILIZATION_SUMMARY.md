## 🐛 Critical Bugs Fixed

### **1. Manual ID Assignment Bug (CRITICAL)**

**Problem:**
- `FinancesPage.tsx` and `DashboardPage.tsx` were manually setting `id: Date.now().toString()` when creating finance records
- Firestore automatically generates document IDs, and the service expects `Omit<FinanceRecord, 'id'>`
- This could cause conflicts and prevent proper document creation

**Fix:**
- Removed manual `id` assignment from all finance record creation
- Changed `FinanceRecord` to `Omit<FinanceRecord, 'id'>` in:
  - `pages/FinancesPage.tsx` (single transaction form)
  - `pages/FinancesPage.tsx` (batch mode)
  - `pages/DashboardPage.tsx` (quick entry form)
- Updated `DataContext.tsx` to accept `Omit<FinanceRecord, 'id'>` for `addFinanceRecord`

**Files Changed:**
- `pages/FinancesPage.tsx`
- `pages/DashboardPage.tsx`
- `context/DataContext.tsx`

## 🗄️ Firestore Structure

### **Collection:** `/finances`

### **Document Fields:**
```typescript
{
  id: string,                    // Auto-generated by Firestore
  type: TransactionType,          // Required: 'Dîme' | 'Offrande' | 'Action de grâce' | 'Offrande du prophète' | 'Dons' | 'Dépense'
  amount: number,                 // Required: Must be > 0
  currency: Currency,              // Required: 'USD' | 'CDF'
  account: FinanceAccount,         // Required: 'Cash' | 'Rawbank' | 'Equity' | 'PayPal' | 'Mpesa' | 'OrangeMoney'
  date: string,                   // Required: ISO date string (YYYY-MM-DD)
  memberName?: string,            // Optional: For income transactions
  notes?: string,                 // Optional: Often used for expenses
  serviceName?: string,           // Optional: For income transactions
  recordedBy: string,             // Required: Name of user who created record
  receiptUrl?: string,            // Optional: URL to receipt/document
  isApproved?: boolean            // Optional: Defaults to true for income, false for expenses
}
```

### **Accounts Supported:**
- `Cash` (default if missing)
- `Rawbank`
- `Equity`
- `PayPal`
- `Mpesa`
- `OrangeMoney`

### **Currencies Supported:**
- `USD` (US Dollars)
- `CDF` (Congolese Francs)

## 🔐 Security & Permissions

### **Firestore Rules:**
```javascript
match /finances/{financeId} {
  allow read, write: if isSuperAdmin() || isFinanceAdmin();
}
```

**Access Control:**
- **SUPER_ADMIN**: Full read/write access
- **FINANCE_ADMIN**: Full read/write access
- **All other roles**: No access (permission denied)

### **UI Permissions:**
- `VIEW_FINANCES`: Required to view finance page
- `CREATE_FINANCES`: Required to create transactions
- `DELETE_FINANCES`: Required to delete transactions

## 📊 Dashboard Integration

### **Finance KPIs on Dashboard:**

1. **Recettes (USD)**
   - **Data Source**: `/finances` collection (real-time listener)
   - **Calculation**: Sum of all USD income transactions (excluding expenses)
   - **Updates**: Real-time via `onSnapshot` listener

2. **Recettes (CDF)**
   - **Data Source**: `/finances` collection (real-time listener)
   - **Calculation**: Sum of all CDF income transactions (excluding expenses)
   - **Updates**: Real-time via `onSnapshot` listener

3. **Alerte Finance** (MorningPulseCard)
   - **Data Source**: `/finances` collection (real-time listener)
   - **Calculation**: This week vs last week offerings (USD equivalent)
   - **Updates**: Real-time via `onSnapshot` listener

4. **Finance Trends**
   - **Data Source**: `/finances` collection (real-time listener)
   - **Calculation**: This month vs last month comparison
   - **Updates**: Real-time via `onSnapshot` listener

### **Account Balances:**
- Calculated on `/finances` page
- Shows balance per account (Cash, Rawbank, Equity, etc.)
- Separate balances for USD and CDF
- Updates in real-time

## 📝 Notes

1. **ID Generation**: Firestore automatically generates document IDs. Never set `id` manually when creating records.

2. **Account Default**: If `account` field is missing, it defaults to 'Cash' for backward compatibility.

3. **Real-Time Sync**: All finance data uses Firestore `onSnapshot` listeners, so changes appear immediately without page refresh.

4. **Currency Conversion**: Dashboard may convert CDF to USD for comparisons (using exchange rate ~2800 CDF = 1 USD).

5. **Transaction Types**: 
   - Income: Dîme, Offrande, Action de grâce, Offrande du prophète, Dons
   - Expense: Dépense

6. **Batch Mode**: Allows creating multiple transactions quickly with shared settings (date, service, type, currency, account).
